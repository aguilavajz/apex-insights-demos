# scripts

## Overview
Database setup and seed scripts for the Enterprise UX Patterns Oracle APEX demo (`2026-03-24-enterprise-ux-patterns`), defining and populating the `demo_invoices` table used by the invoice management pages.

## Interface
- `[01_tables.sql:demo_invoices]` — Oracle table `demo_invoices` with columns:
  - `[01_tables.sql:demo_invoices.id]` — `NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
  - `[01_tables.sql:demo_invoices.client_name]` — `VARCHAR2(100)`
  - `[01_tables.sql:demo_invoices.amount]` — `NUMBER`
  - `[01_tables.sql:demo_invoices.status]` — `VARCHAR2(20)`
  - `[01_tables.sql:demo_invoices.due_date]` — `DATE`
- `[02_data.sql:demo_invoices]` — Seed script inserting three sample rows into `demo_invoices` (`'Acme Corp'`, `'Global Tech'`, `'Innova S.A.'`).

## Invariants
- `[01_tables.sql:demo_invoices.id]` — Primary key identity column (`GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`).
- `[01_tables.sql:demo_invoices.status]` — Check constraint restricts `status` to `'DRAFT'`, `'PENDING'`, or `'APPROVED'`.

## Side Effects
- `[01_tables.sql:demo_invoices]` — Executes DDL (`CREATE TABLE demo_invoices`) in the target Oracle schema.
- `[02_data.sql:demo_invoices]` — Executes three `INSERT INTO demo_invoices` DML statements (`5000`/`'DRAFT'`/`SYSDATE+10`, `12000`/`'PENDING'`/`SYSDATE+5`, `8500`/`'APPROVED'`/`SYSDATE-2`) followed by `COMMIT`.

## Verification
- Run: `sql <username>/<password>@<connection_string> @01_tables.sql` and `@02_data.sql` in SQLcl / SQL*Plus (or execute in order via Oracle APEX SQL Workshop).
