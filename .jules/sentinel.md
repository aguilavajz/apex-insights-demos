## 2026-06-09 - ORDS Handler Input Truncation and Safe Conversion
**Vulnerability:** ORDS handlers directly assigned unrestricted HTTP query and body parameters (`p_filter_val`, `p_name`, `p_email`) to fixed-width `VARCHAR2(200)` variables and converted path parameter `:id` directly using `TO_NUMBER(:id)` without error handling. Oversized inputs triggered unhandled `ORA-06502: numeric or value error: character string buffer too small` and non-numeric `:id` values triggered unhandled `ORA-01722: invalid number` exceptions.
**Learning:** In PL/SQL ORDS REST handlers, incoming parameters are bound dynamically. Assigning parameters larger than the receiving variable's declared size throws `ORA-06502` before validation logic can execute, and invalid number formatting raises unhandled `ORA-01722`, causing unhandled 500 errors.
**Prevention:** Always truncate string inputs using `SUBSTR(p_param, 1, max_len)` during initial sanitization and use `TO_NUMBER(p_param DEFAULT NULL ON CONVERSION ERROR)` for numeric conversions in ORDS templates.
